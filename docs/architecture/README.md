│                      前端应用层                           │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐      │

│  └─────────────┘  └─────────────┘  └─────────────┘      │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                      云服务层                            │

## 技术栈选型

### 前端技术

| 平台 | 技术栈 |
|-----|-------|
| 微信小程序 | 原生小程序框架、WXSS |
| Android | Kotlin / Java、MVVM架构 |
| 音频播放 | 各平台原生音频API |

### 后端/云服务

| 服务 | 技术选型 |
|-----|---------|
| 云函数 | Node.js |
| 数据库 | 云开发数据库（MongoDB兼容） |
| 存储 | 云存储（音频文件） |
| 认证 | 微信登录 / OAuth2 |

### 语料库管理

| 工具 | 说明 |
|-----|------|
| Python脚本 | 数据格式转换、音频批量生成 |
| edge-tts | Microsoft Edge语音合成 |
| Markdown | 语料库文档格式 |

## 系统边界

- 纯前端应用，无自建后端服务器
- 依赖微信云开发服务
- 语料库数据本地部署/云端同步
