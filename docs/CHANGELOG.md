# 变更与版本管理

## 版本号规则

采用语义化版本：`MAJOR.MINOR.PATCH`

- MAJOR：重大功能变更/架构调整
- MINOR：新功能添加
- PATCH：Bug修复/小优化

## 更新日志

### v1.2.0 (开发中)
- Android 版本完善
  - 自动播放功能修复：播放顺序"单词→单词中文→词组→词组中文→例句→例句中文"
  - 组号选择器：50 词一组，可选择第几组播放
  - 播放时屏幕常亮
  - 词组/例句中文显示修复（Gson @SerializedName）
  - 音频复读空隙（1-5秒间隔，供用户自我复读）
  - 复习模式重写：3步流程（单词展示→选择题→填词），间隔重复算法 1/3/7/15 天
  - 错题自动记录到 WrongWord 表
  - kapt 替换为 KSP（解决 JDK 17+ 模块访问问题）
  - 自动播放重复次数选择（×1 / ×2 / ×3）
  - 全屏卡片模式：根据当前播放音频展示单词、词组、例句及释义，底部显示 AUTOPLAY MODE 提示
  - 语料库选择记忆（SharedPreferences），默认 CET4
  - 学习进度记忆（组号+词号），应用重启后自动恢复上次学习位置
