## 模块职责

| 模块 | 职责说明 |
|-----|---------|
| 学习模块 | 新单词学习、单词展示、音频播放 |
| 复习模块 | 艾宾浩斯复习、复习计划管理 |
| 测试模块 | 单词测试、选择题/拼写题 |
| 统计模块 | 学习进度、统计数据、成就系统 |
| 设置模块 | 语料库切换、学习参数设置、账户管理 |
| 语料库模块 | 多语料库管理、数据加载 |

## 核心业务流程

### 学习流程
```
选择语料库 → 加载单词列表 → 展示单词 → 播放音频
→ 显示释义/词组/例句 → 用户标记掌握 → 更新进度
```

### 复习流程
```
检查复习计划 → 加载待复习单词 → 复习测试
→ 更新复习状态 → 调整复习间隔
```
