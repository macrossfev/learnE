# 安全与权限文档

## 认证方式

| 平台 | 认证方式 |
|-----|---------|
| 微信小程序 | 微信登录（wx.login） |
| Android | OAuth2 / 账号密码 |

## 权限体系

### 用户权限
- 查看单词列表
- 学习/复习/测试功能
- 个人数据管理

### 数据权限
- 用户仅能访问自己的学习数据
- 语料库数据公开访问

## 安全策略

### 数据安全
- 用户数据隔离存储
- 云函数身份验证
- 数据所有权校验

### 接口安全
- 云函数入口验证
- 参数校验
- 防止SQL注入

### 音频资源
- 云存储访问控制
- 资源URL签名
