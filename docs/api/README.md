# API接口文档

## 云函数接口

### 1. getWords - 获取单词列表

**接口地址**: 云函数 `getWords`

**请求方式**: 云函数调用

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| corpus | string | 是 | 语料库标识（cet4/catti） |
| limit | number | 否 | 返回数量，默认20 |
| offset | number | 否 | 起始位置 |

**响应参数**:
| 参数 | 类型 | 说明 |
|-----|------|------|
| words | array | 单词列表 |
| total | number | 总数量 |

---

### 2. updateProgress - 更新学习进度

**接口地址**: 云函数 `updateProgress`

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| wordId | string | 是 | 单词ID |
| status | string | 是 | 状态（new/learning/mastered） |
| corpus | string | 是 | 语料库标识 |

---

### 3. getReviewList - 获取复习列表

**接口地址**: 云函数 `getReviewList`

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| corpus | string | 是 | 语料库标识 |
| date | string | 否 | 复习日期 |

---

## 错误码说明

| 错误码 | 说明 |
|-------|------|
| 0 | 成功 |
| 1001 | 参数错误 |
| 1002 | 语料库不存在 |
| 1003 | 用户未登录 |
| 2001 | 数据库错误 |
